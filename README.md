# 🛒 UniMart

A student marketplace platform where students can buy and sell items around campus.

## 🚀 Features

- User authentication
- Student marketplace
- Create product listings
- Cloud database
- Search products
- Seller information
- Responsive design

## 🛠 Built With

- HTML
- CSS
- JavaScript
- Firebase

## 📸 About

UniMart helps students easily find and sell items within their campus community.
