# 🛒 UniMart

![UniMart](https://img.shields.io/badge/Status-Live-success)

UniMart is a campus marketplace platform where students can buy and sell items easily within their school community.

## 🌍 Live Demo

https://unimart-34959.web.app

## 🚀 Features

✅ User Authentication  
✅ Student Marketplace  
✅ Create Product Listings  
✅ Firebase Cloud Database  
✅ Product Search  
✅ Seller Information  
✅ Responsive Design  


## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Firebase Hosting
